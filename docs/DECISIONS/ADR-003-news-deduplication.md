# ADR-003 — تشخیص خبر تکراری چندلایه

## وضعیت

پذیرفته‌شده — 2026-07-17

## زمینه

بازنشر گسترده اخبار فوتبال. حذف کور باعث از دست رفتن به‌روزرسانی مهم می‌شود؛ عدم dedup باعث نویز سردبیر.

## تصمیم

Pipeline ترتیبی:

1. **URL Canonical** — نرمال‌سازی و unique per source/global policy  
2. **Content Hash** — hash متن نرمال‌شده  
3. **Title Similarity** — شباهت تیتر  
4. **Entity Matching** — باشگاه/شخص/تاریخ  
5. **Time Proximity** — پنجره زمانی رویداد  
6. **Embedding Similarity** — pgvector cosine  
7. **AI Confirmation** — فقط موارد مشکوک (آستانه میانی)

نتیجه: اتصال به `NewsEvent` به‌جای حذف کامل؛ جریمه امتیازی برای تکراری بدون تحول.

## پیامدها

- دقت بالاتر با هزینه محاسباتی بیشتر در لایه ۶–۷
- نیاز به تنظیم آستانه‌ها per scope (ایران/اروپا)
- فاز صفر فقط schema و URL/hash آماده می‌کند؛ لایه‌های معنایی از فاز ۴

## جایگزین ردشده

فقط embedding یا فقط URL — هر دو به‌تنهایی نرخ false positive/negative بالا دارند.
