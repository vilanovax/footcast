# ADR-004 — موج استخراج، مشاهدهٔ چندبه‌چند، سبد روزانه

## وضعیت

پذیرفته‌شده — ۱۴۰۵/۰۴/۲۷ (2026-07-18)

## زمینه

صندوق فعلی Event-based است ولی مفهوم «موج استخراج»، «خبر تأییدشده» و «خبر اپیزود امروز» مخلوط شده‌اند. پادکست روزانه ساعت ۱۶:۰۰ (Asia/Tehran) نیاز به انباشت کنترل‌شده و توازن پوشش دارد.

## تصمیم

1. **IntakeWave** برای هر اجرای برنامه‌ریزی‌شده/دستی استخراج.
2. **WaveEventObservation** چندبه‌چند Wave ↔ NewsEvent (نه `NewsEvent.waveId`).
3. **DailyRundown / DailyRundownItem** مستقل از `EventStatus.APPROVED`.
4. توازن پوشش بیشتر بر **مدت تخمینی**؛ حذف خودکار بی‌صدا ممنوع — پیشنهاد REPLACE با تأیید سردبیر.
5. قفل ۱۶:۰۰ با وضعیت‌های `LOCKED` / `REOPENED` + Audit.

## پیامدها

### مثبت

- صندوق موج فقط دلتا/تحول نشان می‌دهد
- سبد امروز تا دeadline جدا از تأیید خبر است
- مدل آماده برای portfolio و Opus روی سبد نهایی

### منفی / ریسک

- پیچیدگی دامنه بیشتر؛ باید UI سه مفهوم را واضح نگه دارد
- تخمین مدت در v1 heuristic است

## جایگزین‌های ردشده

| گزینه | دلیل رد |
|-------|---------|
| `NewsEvent.waveId` تکی | رویداد در چند موج تحول می‌گیرد |
| `SELECTED` به‌جای Rundown | تأیید ≠ حضور در اپیزود امروز |
| حذف خودکار کم‌امتیاز | خلاف اولویت تصمیم انسانی |
